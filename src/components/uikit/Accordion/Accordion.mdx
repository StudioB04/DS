# Accordion

The `Accordion` component reveals and hides content. It is built on the native `<details>` / `<summary>` elements, so it works without JavaScript, is keyboard accessible (`Enter` / `Space` on the summary) and is announced correctly by screen readers. The label supports basic markdown (`strong`, `em`, `br`).

The summary is laid out as: `slotStart` → label → `slotEnd` → chevron. The chevron is always displayed, pushed to the end of the row, and rotates when the accordion opens. On hover, the summary text switches to the brand colour.

## Usage

```tsx
import { Accordion } from "@studio_b04/ds/uikit";

<Accordion label="What is StudioB04?">
  <p>A design studio.</p>
</Accordion>
```

---

## Props

- `label` (`string`, required): summary text, always visible. Markdown is supported.
- `children` (`ReactNode`, required): content revealed when open.
- `size` (`"sm" | "md" | "lg"`, default `"md"`): size of the summary text, content text and spacing.
- `slotStart` (`ReactNode`): custom content before the label (icon, avatar, badge…).
- `slotEnd` (`ReactNode`): custom content after the label, before the chevron (counter, badge…).
- `name` (`string`): native `name`; accordions sharing a name only allow one open at a time.
- `open` (`boolean`): native `open` attribute.

All other `<details>` attributes (`id`, `onToggle`, `data-*`, `aria-*`…) are forwarded to the root element.

## Opening animation

Opening and closing animate the height and the opacity of the content with pure CSS (`::details-content` + `interpolate-size`).
The duration uses the `--ds-transition-regular` token, so it is disabled when the user prefers reduced motion.
Browsers that don't support `::details-content` yet simply open and close instantly.

## Exclusive group

Give several accordions the same `name` to only allow one open at a time (native `<details name>` behaviour).

<Canvas of={AccordionStories.ExclusiveGroup} />

```tsx
<Accordion label="First question" name="faq" open>…</Accordion>
<Accordion label="Second question" name="faq">…</Accordion>
<Accordion label="Third question" name="faq">…</Accordion>
```

---

## Controlled

`open` sets the initial state; listen to `onToggle` to keep your own state in sync with user interactions:

```tsx
const [open, setOpen] = useState(false);

<Accordion label="Controlled" open={open} onToggle={(e) => setOpen(e.currentTarget.open)}>
  …
</Accordion>
```

## Slots

Use `slotStart` and `slotEnd` to display any React content in the summary:

- `slotStart` is placed before the label: an icon, an avatar, a badge…
- `slotEnd` is placed after the label, just before the chevron: a counter, a status badge…

```tsx
import { Accordion, Badge, Icon, Notification } from "@studio_b04/ds/uikit";

<Accordion label="Need help?" slotStart={<Icon src="circle-question-mark" size={20} />}>…</Accordion>
<Accordion label="Notifications" slotEnd={<Notification value={3} variant="brand" />}>…</Accordion>
<Accordion
  label="Release notes"
  slotStart={<Icon src="rocket" size={20} />}
  slotEnd={<Badge label="v0.2" variant="neutral" size="sm" />}
>
  …
</Accordion>
```
