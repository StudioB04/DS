# Notification

The `Notification` component displays a compact counter, typically next to text or icons to indicate unread items or pending events.

## Default

<Canvas of={NotificationStories.Default} />
<Controls of={NotificationStories.Default} />

---

## Usage

```tsx
import { Notification } from "@studio_b04/ds/uikit";

<Notification value={3} size="md" variant="brand" max={99} />
```

---

## Value and max

`value` is the displayed count. When `value` is greater than `max`, the component displays `max+`.

<Canvas of={NotificationStories.NoLimit} />

```tsx
<Notification value={8} max={99} />
<Notification value={120} max={99} /> // displays: 99+
```

---

## Sizes

Use `size` to control the visual scale: `sm`, `md`, `lg`.

<Canvas of={NotificationStories.Small} />

```tsx
<Notification value={1} size="sm" />
<Notification value={12} size="md" />
<Notification value={120} size="lg" />
```

---

```tsx
<Notification value={3} variant="brand" />
<Notification value={3} variant="alt" />
<Notification value={3} variant="green" />
<Notification value={3} variant="red" />
<Notification value={3} variant="orange" />
<Notification value={3} variant="blue" />

<Notification value={3} variant="yellow" />
<Notification value={3} variant="pink" />
```
